### ECON 8310 – Business Forecasting Semester Project  
### Baseball Object Detection Using Deep Learning

---

## 📌 Project Overview
This project focuses on detecting a moving baseball in training videos using a convolutional neural network (CNN).  

- Goal: build a model capable of drawing accurate bounding boxes around the baseball in each frame.

This work was completed as part of the ECON 8310 Semester Project at the University of Nebraska Omaha.
